# BOOKOFF利益商品検索ツール（静岡・山梨・神奈川）

BOOKOFFグループ店舗の仕入れ価格と、メルカリ・Yahoo!フリマ・Amazon中古の相場を比べて、**利益が出る商品**を探すツールです。Amazonとフリマの両方で定価を超えて売れている**プレミア商品**を、BOOKOFFで定価以下で仕入れる探し方にも対応しています。PC・iPhone・Androidのブラウザで使えます。

## かんたん起動（プログラミング不要）

1. **Node.js を入れる**（初回のみ）：https://nodejs.org/ja から「LTS」版（バージョン22.13以上）をインストールします。
2. **フォルダを開いて起動する：**
   - Windows：`起動（Windows）.bat` をダブルクリック
   - Mac：`起動（Mac）.command` をダブルクリック（初回は右クリック→「開く」）
3. 数秒でブラウザに http://localhost:3000 が開きます。黒い画面（ウィンドウ）を閉じると停止します。

**スマホから使う：** PCとスマホを同じWi-Fiにつなぎ、起動画面に出る `http://192.168.x.x:3000` をスマホのブラウザで開きます。ホーム画面に追加するとアプリのように使えます。

**設定（任意）：** `config.env.example` を `config.env` という名前でコピーし、必要な行を書き換えます。
- `APP_PASSWORD`：開くときにパスワードを聞くようにする（同じWi-Fiの人に触られないため。おすすめ）
- `KEEPA_API_KEY`：Amazon中古価格・定価を自動で取得する（Keepaの有料APIキー）
- `PORT`：ポート番号（既定3000）
- `SEED_DEMO=0`：架空のデモデータを入れない

データは `data/app.db` に保存されます。**バックアップはこのファイルをコピー**してください（ツールを止めてからコピーすると確実です）。

## 使い方

1. **データを入れる**（「取込・出力」）：テンプレートCSVを使って、店頭で確認したBOOKOFFの在庫・価格・定価と、各アプリで確認した相場を取り込みます。商品詳細から1件ずつ登録・編集・削除もできます。
2. **利益商品を探す**（「利益商品一覧」）：最初から「利益が出る商品のみ」を表示します。3販路のうち一番儲かる販路で判定し、利益は緑、損失は赤で表示します。
3. **プレミア商品を探す**：一覧の「プレミア商品を探す」ボタンで、Amazon中古とフリマの売却済み価格の**両方が定価超え**で、BOOKOFFでは**定価以下**、かつ利益が出る商品をプレミア率順に表示します。
4. **確認待ち**：Amazonでは定価超えだがフリマの売れた価格が未登録の候補です。「メルカリで探す」「Yahoo!フリマで探す」で検索を開き、「売り切れ」で絞り込んで、売れた価格を登録します。
5. **行く店舗を決める**（「店舗マスタ」）：県を選ぶと、利益商品のある店舗を想定利益合計の多い順に表示します。店舗をタップするとその店舗の商品一覧を開きます。
6. **在庫の鮮度**：確認から3日を過ぎた「在庫あり」は「要再確認」と表示され、店舗画面の「確認済」にも数えません（日数は設定で変更）。もう一度確認して登録し直すと最新の状態に戻ります。
7. **設定**：販路ごとの手数料率・送料、Amazonのカテゴリー別手数料（成約料・最低手数料）、その他費用、相場の優先順位を変更できます。
8. **推定相場は自動で計算**：売却済み価格を登録すると、直近30日（設定で変更可）の中央値を推定相場として自動保存し、利益計算に使います。
9. **重複商品の統合**（「取込・出力」）：JANとISBNで同じ商品が2件以上あると表示されます。「この商品に統合」で在庫と相場を1つにまとめます。
10. **店舗マスタの見直し**（「取込・出力」）：公式の店舗一覧から作ったCSVを「差分だけ確認」に入れると、保存せずに新店・変更・閉店候補を表示します（手順は `docs/data-sources.md`）。

## 自動取得について

- **Amazon中古価格・定価**：Keepa API（有料）のキーを設定すると、一覧の「Amazon中古価格を更新」で取得できます（本番APIでの動作確認は未実施）。
- **メルカリ・Yahoo!フリマの相場、BOOKOFFの店舗在庫**：公式に使えるAPIが無いため**自動取得は未実装**です。規約に反する収集は行いません。CSVか手動で登録してください。

詳細は `docs/data-sources.md` を参照してください。

## 開発者向け

```bash
npm install          # オフライン環境では ./scripts/link-offline-deps.sh
npm run build        # dist/ を作成
npm start            # http://localhost:3000
npm run typecheck && npm test && npm run test:e2e
```

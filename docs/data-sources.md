注意点:
- 公式一覧には BOOKOFF 以外のグループ業態（B・STYLE、あそビバ、aidect、Rehello by BOOKOFF、Japan TCG Center）も含まれる。業態区分「関連」として分類した。
- 綱島樽町店・横浜瀬谷南台店・古淵駅前店のように、別館が別店舗IDで掲載されるケースがある。公式IDどおり別店舗として登録した。
- 公式サイトには閉店店舗ページが「【閉店】」付きで残る例がある（他県で確認）。店舗状態「閉店」と後継店舗IDで表現できるようにした。

### 店舗マスタの定期見直し手順（3か月に1回程度を推奨）

1. 上記3県の公式一覧ページをブラウザで開き、各店舗の「公式店舗ID（shop番号）・店舗名・都道府県・所在地」を店舗テンプレートCSVに書き写す（自動収集はしない）。
2. 取込・出力画面の店舗マスタ欄で「差分だけ確認」にそのCSVを指定する。DBには保存されず、次が表示される。
   - 【追加】CSVにあってDBに無い店舗（新店）
   - 【変更】店舗名・所在地・状態などが変わる店舗（改称・移転）
   - CSVに無い営業中の店舗（閉店・改称の候補）
3. 「CSVに無い店舗」は公式サイトで確認し、閉店なら `状態=閉店`（移転・統合先があれば `後継店舗ID`）の行をCSVに加える。
4. 内容に問題がなければ、同じCSVを通常の取込欄で取り込む。変更は店舗ごとの履歴（store_events）に残る。

## 5-2. 推定相場の自動算出

- 外部へのアクセスはしない。登録済みの売却済み価格（`price_type=sold`、実データのみ）から、商品×販路ごとに直近N日（設定画面、既定30日）の中央値と件数を計算し、推定相場（`estimate`）として保存する。
- 情報取得元は「自動算出（売却済み価格の中央値）」。CSV・手動で登録した推定相場は上書きしない。取得日時は期間内で最新の売却済み価格の日時。
- 相場CSVの取込、売却済み価格の手動登録・削除、商品の統合、期間の変更のときに自動で再計算する。設定画面の「推定相場を今すぐ再計算」でも実行できる（日数が経って期間から外れた価格を反映するため）。
- サンプル数の付いた1行（例：直近5件の中央値）も1件として数える。

## 6. 手数料の初期値

設定画面から変更可能。初期値はDBの設定に保存され、計算コードには埋め込んでいない。

| 販路 | 初期値 | 根拠 |
|---|---|---|
| メルカリ | 10% | 一律10%とする複数の解説記事（2026年時点） |
| Yahoo!フリマ | 5% | 2021年1月に10%→5%へ値下げ、以降5%（税込）とする解説記事 |
| Amazon中古（本・CD・DVD・ゲーム） | 15%、最低手数料なし＋カテゴリー成約料（本80円、CD・DVD140円） | Amazon出品サービスの料金を引用した解説記事 |
| Amazon中古（ホビー・家電・その他） | 15%・最低30円（保守的な初期値） | 実際はカテゴリーで8〜15%。設定画面のカテゴリー別手数料で調整 |

キャンペーンや規約改定で変わるため、利用前に各公式ヘルプで確認すること。

## 7. 将来の接続候補（要調査）

- 両社が公式にデータ提供（提携・データ販売）を始めた場合は、`MarketPriceProvider` を実装して差し替える。
- 利用者がブラウザで閲覧した価格を手入力しやすくする「クリップボード貼り付け取込」。
- BOOKOFF店舗の在庫は、店舗での目視確認結果をスマホから登録するフローが最も確実。

## 8. 実装しないこと（明示）

- 規約に反するスクレイピング、ログイン・認証の回避、アクセス制限・bot対策の回避。
- 非公式APIの呼び出し。
- Yahoo!オークション・Yahoo!ショッピングの価格による相場代替。
